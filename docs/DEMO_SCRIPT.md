# ScalarScope Demo Script

**Duration:** 5 minutes
**Audience:** Researchers, reviewers, collaborators
**Goal:** Walk the four tabs the shell actually opens

The shell tabs are **Home**, **Compare**, **Guide**, and **Settings**.

## Pre-Demo Setup

1. Launch ScalarScope
2. Keep the window at least 1400×900 if the room can see it
3. If you do not have two traces, use **Try Example** on Home

## Script

### 0:00–1:00 | Home

**[Home]**

> "This is a review of two runs. I load them here, or I open the example."

- Click **Compare Two Runs**, or **Try Example** when you have no files of your own
- If a comparison is already listed, that list is the comparison log. It is not the stored-path list in Settings

### 1:00–3:00 | Compare

**[Compare]**

- Load the baseline under Path A and the other run under Path B
- Path A is `#4ecdc4`. Path B is `#ff6b6b`
- The bundled demo assigns orthogonal professors to Path A and correlated professors to Path B

> "A delta is on this page only when the comparison fired it. A missing steady-state milestone is not a measured tie on stabilization time. An outlier count that fell is not a report that no failures occurred."

This script does not read coordinates off the demo.

### 3:00–4:00 | Guide

**[Guide]**

- Open Guide and read the recap
- The recap labels Path A Orthogonal in `#4ecdc4` and Path B Correlated in `#ff6b6b`, the same assignment Compare uses
- The recap states the bundled demo's claim about evaluator geometry. Point at that text. Do not add a coordinate

### 4:00–5:00 | Settings

**[Settings]**

- About calls the bundle hash a SHA-256 content check, not a signature
- The first-run control clears a flag. It does not start the demo
- Stored paths can be cleared here. Home, Compare, Guide, and Settings do not show that list
- Pressing S tries to write a PNG when a run is open. No notification is shown. Ctrl+E is not mapped

## What this script does not show

- A notification after S
- A Ctrl+E export
